ByteLens

Informativa sulla privacy

Ultimo aggiornamento: agosto 2026

ByteLens è progettato attorno a un principio semplice: le tue immagini non lasciano mai il tuo dispositivo. Questa pagina spiega come vengono gestiti i dati.

Elaborazione delle immagini

Tutta la compressione e il ridimensionamento avvengono localmente nel tuo browser tramite le API HTML Canvas. I file selezionati non vengono caricati, salvati o trasmessi ad alcun server. Chiudendo la scheda, i dati dell'immagine vengono eliminati dalla memoria.

Cookie e archiviazione locale

ByteLens salva un'unica preferenza (tema chiaro/scuro) nell'archiviazione locale del browser. Non usiamo cookie di tracciamento proprietari.

Statistiche

Potremmo utilizzare uno strumento di analisi del traffico aggregato e anonimo per capire quante persone usano il sito. Questi dati non permettono di identificarti personalmente.

Donazioni

I pulsanti di donazione rimandano a piattaforme esterne (es. Buy Me a Coffee, Ko-fi, PayPal, GitHub Sponsors). Le transazioni sono gestite da tali piattaforme secondo le loro rispettive informative sulla privacy.

Contatti

Per domande su questa informativa puoi aprire una issue sul repository del progetto.
